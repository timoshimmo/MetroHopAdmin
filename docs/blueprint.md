# **App Name**: MetroTrack

## Core Features:

- Pickup Location Display: Display pickup locations for customer selection.
- Sequence Drop Off: Show a sequential drop-off route for customers.
- Drivers Outsourcing: Manage the assignment of drivers to external operations.
- Pick Up Request Display: Display pick up requests to admin.
- Vehicle Maintenance: Track and record vehicle maintenance activities.
- Drivers On Site/Bus Number: Display the buses available and their locations in real-time.
- Customer service summary using LLM tool: Tool to summarize support cases.
- Admin Login Page: Secure login page with input validation to protect admin access.

## Style Guidelines:

- Primary color: Deep green (#1B5E20) to evoke growth, reliability, and safety.
- Background color: Light green (#E8F5E9), a desaturated and bright shade to support a clean and airy theme.
- Accent color: Yellow-green (#9CCC65), analogous to green to provide a cheerful and contrasting highlight.
- Body and headline font: 'Roboto' sans-serif, for a modern, clean, and easily readable look suitable for both headlines and body text.
- Use consistent, professional, and easily recognizable icons for navigation and data visualization.
- Design a clear and intuitive dashboard layout with key performance indicators (KPIs) prominently displayed for quick insights.
- Use subtle transitions and animations to enhance user experience and provide feedback on interactions without being distracting.
